# TerraformAws architecture

The editable AWS architecture diagram uses AWS service icons and AWS Cloud, service grouping, and connector conventions. Open [ARCHITECTURE.drawio](ARCHITECTURE.drawio) in diagrams.net (draw.io) to view or edit it.

It depicts the deployed HTTP API and REST API paths, their shared Lambda backend, IAM execution role, CloudWatch Logs, and the Route 53 and ACM custom-domain setup in `us-east-2`. The commented S3 and IAM examples in `iam.tf` are inactive and are omitted.
